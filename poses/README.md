# ポーズの棚

一つのポーズを一つの JSON にする。`joints` に関節ごとの回転（度、Euler XYZ、親の関節に対する回転）を書く。書かない関節は 0。

```json
{ "name": "直立", "joints": { "shoulder_r": [0, 6, 0], "elbow_r": [-8, 0, 0] } }
```

- 関節: `pelvis`（体全体）、`spine`、`chest`、`neck`、`head`、`shoulder_*`、`elbow_*`、`wrist_*`、`hip_*`、`knee_*`、`ankle_*`（`_r` は人形の右、`_l` は左）。
- 基本の姿勢は直立で腕を下ろした形。人形は -Y を向き、+X が人形の左。
- 回転の向き: x 正で下向きの部位（腕・脚）は後ろへ、上向きの部位（背骨・首・頭）は前へ倒れる。y 正で下向きの部位は人形の右へ開く（右腕なら外、左腕なら内）。z 正で上から見て左回り（人形の左へ振り向く）。
- 剣（`hold: sword`）は右の手首に付き、腕を下ろした形で刃が前を向く。`wrist_r` の x で刃の上下、z で左右を向ける。
- 足は自動で床に着く（低い方の足に合わせる）。

| ファイル | ポーズ |
| --- | --- |
| `stand.json` | 直立 |
| `sword_guard.json` | 剣を構える（中段・右足前・両手） |
| `look_back.json` | 振り返る（背を向けて左の肩越しに見る。`facing: 180` で使う） |

## 外部の素材（調べただけ。まだ取り込んでいない）

| 素材 | 利用条件 | 取り込み方 |
| --- | --- | --- |
| CMU Graphics Lab Motion Capture Database | 無料。商用の作品に含めてよいが、データそのものの再配布・販売は不可 | BVH 版（cgspeed の変換）を使う。bpy の BVH 読み込みで一コマを選び、骨ごとの回転をこの棚の関節名に写して JSON にする |
| Mixamo（Adobe） | Adobe アカウントで無料。作品への利用は可、アニメーションの生データの再配布は不可。API はなく手で落とす | FBX を手で落とし、上と同じく一コマを JSON に写す |
| Bandai Namco Research Motion Dataset | CC BY-NC-ND 4.0（非商用・改変不可）。作者個人の参照に限るなら検討の余地あり。出版物に使う絵の下絵には使わない | BVH。上と同じ |

- 写すときの注意: 素材の基本の姿勢（多くは T ポーズ）とこの人形の基本の姿勢（腕を下ろす）の差を、肩の回転で打ち消す。軸の向き（Y 上か Z 上か）も合わせる。
- 素材の生データは git に入れない（再配布になる）。棚に置くのは写した JSON だけにする。
